## `$ cat ./projects.md`

### 🔴 Real-Time Stock Market Streaming Pipeline
> AlphaVantage → **Kafka** → **PySpark Structured Streaming** → **Delta Lake**

Built a live streaming pipeline that ingests stock prices for 5 symbols, processes them in near real-time using PySpark on Databricks, and stores results in Delta Lake via Unity Catalog.

---

### 🟠 Cloud ELT Pipeline — Financial Fraud Detection
> **AWS S3** → **Glue** → **Athena**

Designed a serverless ELT pipeline on AWS to process financial transaction data, detect anomalies, and make data queryable via Athena.

---

### 🟡 Data Warehouse — Healthcare Analytics
> **Snowflake** (Star Schema) + **AWS S3**

Modeled a 3-layer data warehouse (Raw → Staging → Analytics) with a clean star schema — FACT_ADMISSIONS with dimension tables for Patient, Hospital, Ward, Severity, and Date.

---

### 🔵 ETL Batch Pipeline — E-Commerce Sales
> **Databricks** + **Delta Lake**

Built a batch ETL pipeline for processing e-commerce sales data, applying transformations and writing optimized Delta tables for downstream analytics.

---

### 🟢 Weather Data Pipeline *(In Progress)*
> **AWS Glue** + **S3** + **Python**

Building an automated weather data pipeline that fetches, transforms, and stores weather records on AWS.
